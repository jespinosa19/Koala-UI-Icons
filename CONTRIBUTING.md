# Contributing to Koala Icons

Thanks for helping. Icon requests, drawing fixes and new icons are all welcome.

## Ways to help

| You want to | Do this |
| --- | --- |
| Ask for an icon | [Open an icon request](../../issues/new?template=icon_request.yml) |
| Report an icon that draws wrong | [Open a bug report](../../issues/new?template=bug_report.yml) |
| Draw a new icon or fix one | Open a pull request, one icon per pull request |

## How this repository is published

This repository is **generated** from the Koala UI source repository on every release. The marker
file `.koala-public` says so. You open issues and pull requests **here**, as usual. When a pull
request is accepted it is applied in the source repository with you as co-author, and it reaches
this repository and npm with the next release. The pull request is then closed with a link to that
release; closed, not merged, is normal here.

## Local setup

You need Node.js 20 or newer.

```bash
git clone https://github.com/<you>/koala-ui-icons.git
cd koala-ui-icons
npm install
npm run lint    # checks every master against the spec
npm run build   # generates src/icons and compiles dist/
```

```
svg/          24 px masters, the source of truth
svg-sm/       small masters for 16 px and below (only where an icon needs one)
meta/         category, tags and fill roles per icon, one file per category
src/          the React wrapper; src/icons is generated by the build
SPEC.md       the drawing spec
```

## Drawing an icon

Read [SPEC.md](./SPEC.md) first. The short version:

- **24 px canvas, 1.75 stroke**, round caps and joins, centrelines inside 2 to 22.
- **Live strokes in `currentColor`**, no fills (except the dot), no colours, no outlined shapes.
- **Soft corners**: every corner is the spec's one-cubic soft corner, never a sharp vertex.
- **Follow Phosphor's construction** where Phosphor has the object: same parts, pose and
  proportions. What makes the icon ours is the stroke, the corners and the grid.
- **Name it like Phosphor** when Phosphor has it, kebab-case on disk.
- Add the icon to the right file in `meta/` with its category and 4 or more search tags.

`npm run lint` checks the mechanical half of the spec and `build` refuses to run while any icon
fails. The rest (optical weight, how it sits next to its neighbours) is reviewed by eye.
